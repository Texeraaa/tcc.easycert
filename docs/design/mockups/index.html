Como usar estes mockups

São HTML estático navegável. Toda interação (toggles, dropdowns, side panels, atalhos de teclado, toasts) é vanilla JS em _shared.js. Design tokens e componentes em _shared.css. Não representa a stack final (Next.js 15 + Tailwind v4 + shadcn/ui) nem substitui code review: serve para alinhar linguagem visual, estados e densidade antes da implementação em produção.
